# Earth Texture Credits

- `earth-blue-marble.jpg` — NASA Blue Marble Next Generation imagery
- `earth-night.jpg` — NASA Earth at Night (Black Marble) imagery
- `earth-topology.webp` — derived elevation/bump map (converted from the
  original PNG for size; bump maps read a single channel, so the WebP's
  grayscale encoding is lossless-equivalent in use)

Sourced from the `three-globe` example assets
(https://github.com/vasturiano/three-globe), MIT license.
Underlying imagery courtesy of the NASA Visible Earth project
(https://visibleearth.nasa.gov) — public domain.
